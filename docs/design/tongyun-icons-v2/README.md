# 橦云产品图标与头像 · V2

打开 index.html 查看 18 款整套预览。每款一个目录，manifest.json 记录名称、符号、色彩和类别。

## 文件

- icon.svg / icon-1024.png / icon-512.png：应用图标
- avatar.svg / avatar-512.png / avatar-256.png：圆形头像（真实透明边角）
- favicon.svg / favicon-16.png / favicon-32.png / favicon-64.png：网页小图标
- social.svg / social-1200x630.png：分享封面

前六款延续 V1；官网复用 tongyun-scaffold/brand/yunya-mark.svg，其余按产品 README 确定含义并绘制。Image 为形象风格工具，使用人像取景符号；Studio 为集成开发工作台。Planner Pro 仅作手帐家族衍生款，不假定已取得其私有仓内容。Skills 是整库身份，不给内部每一项技能虚构独立产品。Work 是工人工作区工具标识。

本目录不替换产品仓、系统安装图标或远程账号头像。Verse 的现有深绿云标保留；候选仅供比较。分色系列来自用户本轮确认方向，不覆盖 scaffold 中正式主标规范。

本目录提供可直接使用的 SVG、PNG、提示词与离线预览页。仅需打开本地文件，无项目服务。生成脚本含原工作区路径，因此不随本仓素材包复制。

## 可复用提示词

- [PROMPTS.md](PROMPTS.md)：风格母版、18 款产品指令、SVG 制作、头像 / favicon / 分享封面和修正提示词。
- [prompts.json](prompts.json)：18 条完整独立提示词，带相对参考素材路径，供复制或批量工具读取。

提示词是从 SVG 成稿提炼的设计规范，不是原图的历史生成记录。
