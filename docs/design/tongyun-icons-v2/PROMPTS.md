# 云芽产品家族 · 可复用设计提示词

版本 1.0 · 2026-10-29

## 先选正确的用法

本套图标原稿由 SVG 直接绘制，并通过浏览器导出 PNG。下面是从成稿整理的设计提示词，不是“原图生成记录”。图像模型可用于探索相近风格，不能仅靠文字保证精确色值、透明通道或跨产品几何一致。需要一致交付时，优先复用本目录 SVG 的底板和云朵，只编辑功能符号。

- **给编码 Agent**：使用第 3 节矢量提示词，提供参考 SVG 和目标产品信息。
- **给图像模型**：使用第 1 节母版 + 第 2 节产品指令 + 负面约束，同时附上 `overview.png` 和对应参考图。只有支持参考图的工具才能利用附图；不要声称文字提示等于精确复刻。
- **批量使用**：`prompts.json` 包含 18 条完整独立提示词，可直接复制单条 `prompt`。`reference` 是相对本目录的素材路径，不代表已自动附图或调用 API。
- **后续扩展**：先确定产品职责和唯一符号，再选自然色。禁止仅按名字猜功能。品牌主标与官网使用现有正式 SVG；Verse 分色款是候选，不覆盖现有正式标志。

## 1. 风格母版

```text
为橦云产品家族设计一枚温暖、简洁的应用图标，延续参考图中的云芽风格。正面平视、二维矢量感，低饱和自然色，大圆角方形底板，奶油色软云作为下半部的共同视觉锚点，一个清晰的产品功能符号从云后露出或与云结合。图形以圆润的粗线条、简洁的填色块和充足留白构成，端点圆滑，视觉重量适中，不做细碎装饰。
以 1024×1024 为设计坐标：分色系列底板位于 x=64、y=64，边长 896，圆角约 218；主体大致落在 x=270–745、y=250–730，云在中下方，符号沿垂直中轴平衡。共用云朵的形状、位置、大小和基线，不因换产品随意改变。允许光学微调，但不能让某一枚明显更重或更满。
底色使用指定产品色；符号以柔和抹茶绿 #658853 为主，少量蜜桃珊瑚 #E9947C 为辅助，云使用奶油色 #FFF8E6。除现有参考图已使用的极轻柔渐变外，以平涂为主，不新增明显高光、材质或投影。外部圆角区域透明。不要在图标内写字或放产品名称。请同时考虑 32px、48px、64px 的辨识度。

避免：3D 建模、玻璃拟态、金属反光、塑料高光、厚重投影、霓虹、强对比渐变、紫蓝科技光效、写实云层、照片纹理、手写涂鸦、卡通人物表情、复杂背景、多重边框、过多小装饰、细线、文字、水印、画面中的棋盘格、直接复制其他品牌 Logo。温暖手帐气质不等于纸张纹理或文具堆叠。
```

## 3. 给编码 Agent 的 SVG 制作提示词

```text
请在当前云芽图标家族基础上新增一个产品标识。
产品名：[名称]
实际职责：[用一句话描述用途]
唯一功能符号：[符号]
底板色：[HEX]
参考文件：[现有 icon.svg 路径]

先读取参考 SVG。复制既有底板与云朵的原路径、坐标、大小和基线；保留统一留白，不凭目测重画整套框架。只替换功能符号与批准的产品色。主画布 1024×1024，使用 path、circle、rect 等原生形状，不嵌入远程资源、字体、位图或外链。粗线条和圆角端点与相邻产品一致；没有独立功能需求时不加装饰。

若做正式品牌主标或官网标识，直接复用 yunya-mark.svg，保持其完整配色与路径，不套分色系列的坐标和色值。

交付独立 icon.svg、avatar.svg、favicon.svg、social.svg。圆形头像应有真正圆形底色和透明外角，主体处于安全区域；favicon 必须在实际 16/32/64px 下复核，必要时删去次要细节；分享封面使用 1200×630 暖灰底，左侧图标、右侧产品名与简短英文名。检查资源加载、文字、几何与透明通道后再输出 PNG，并给出本机预览与检查记录。

本任务只生成资源；除非已授权接入，不替换产品仓文件、安装应用图标或远程账号头像。
```

## 4. 输出形态提示词

### 圆形头像

```text
使用这枚已确认的产品 SVG 制作圆形头像。保留功能符号与云的相对位置、颜色和笔画；以产品底色填充正圆，圆外透明。主体不可被圆形裁切，中心与原图一致。输出 512 和 256 PNG，以及保留可编辑路径的 SVG。不要仅给原方形图加一个圆形描边。
```

### 网页小图标

```text
基于已确认 SVG，生成 16/32/64px favicon。先观察实际尺寸，保留能识别产品的主要符号，减少在 16px 下糊成噪声的次要线条。保持色彩与轮廓家族关系；允许为小尺寸单独做光学修正，不把大图无脑缩小后声称通过。输出 favicon.svg 与对应 PNG。需要 ICO 时明确额外生成，不把 PNG 改后缀伪装为 ICO。
```


## 5. 针对性修正提示词

- **符号过满**：只缩减功能符号的占用范围，底板和云的路径及坐标保持不变；以 API/Git 参考款的视觉重量为准。
- **太像通用科技软件**：去掉立体材质、高光和硬边，把线端改圆，恢复抹茶绿、奶油云与低饱和底色；保留产品功能符号。
- **太像儿童贴纸**：去掉表情、拟人和散落装饰，保留几何块面与单一符号；不要通过降低全部对比度来假装柔和。
- **看不出产品区别**：只改功能符号的结构，让它对应真实操作；不要仅换底色或加产品文字。
- **头像裁切**：只处理圆形底与主体安全区，不让符号或云碰到裁切边缘。
- **小尺寸糊掉**：在实际 16/32px 下删去次要细节、加粗必要笔画；保留源 SVG 大尺寸版，另存小尺寸变体。

## 6. 交付检查

1. 同一排比较底板、留白、云的位置与视觉重量，而不是每枚单看“好不好看”。
2. 确认功能符号和实际产品职责一致；候选标识不要当正式品牌标志发布。
3. 分色系列与正式主标的色值分别遵守各自源 SVG，不混用。
4. 实际查看 16/32/48/64px、圆形裁切和浅深背景；记录未处理的小尺寸问题。
5. PNG 分辨率与命名一致；透明角应检查 alpha，而不是把黑底或棋盘格当透明。
6. SVG 无外链与字体依赖；分享封面的中文与英文拼写正确。
7. 改动的是资源包还是产品正式入口，交付时说清楚；“生成完毕”不等于“已安装、已发布”。

## 7. 原始设计约束与参考

- `manifest.json`：产品职责符号、名称与分色。
- `overview.png`：整套色彩、比例与排列参考。
- 各产品 `icon.svg`：几何、颜色与分层的准确依据。
- 正式云芽源位于 `repos/tongyun-scaffold/brand/yunya-mark.svg`；品牌规范见该仓 `brand/README.md`。此处只说明来源，不要求在安装资源包后仍能访问那个仓。

精确复现时以本包提供的实际 SVG 为准；文中的范围和风格词描述共同方向，不替代每枚图的真实坐标。
