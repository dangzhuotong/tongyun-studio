## 1. 品牌传承与产品定位

橦云工作台是开发者套件的中心枢纽（文件 · 运行 · 接口 · 数据 · 版本）。应用图标（App Icon / 头像）需严格继承橦云（Tongyun）家族视觉语言，同时准确传达“一站式集成工作台”的产品特质。

### 核心视觉资产对齐

| 视觉元素 | 取值规范 | 设计用意 |
| :--- | :--- | :--- |
| **底座形状** | macOS 标准 Squircle（`x=100, y=100, w=824, h=824, rx=200`） | 保证与 macOS Dock、Launchpad 及同门桌面应用（tongyun-api / tongyun-git）完全对齐 |
| **主基底色** | 暖奶茶渐变 `#F5E8D6` $\to$ `#E2C7A3` | 橦云经典手帐暖奶茶底色，温暖克制，区别于传统冰冷的高饱和软件图标 |
| **云朵底座** | 云乳白 `#FCF4E1` 几何连环云 | 象征「橦云」底座，托起上方的开发者工坊 |
| **生机云芽** | 芽绿 `#4D7C5D` $\to$ 嫩绿 `#A4C48C` | 代表工程的活力、新生与茁壮成长 |
| **状态点缀** | 蜜桃红 `#C2593F` / `#EF8F7B`、天青 `#3E6F9E` | 用于接口状态、Git 分支与终端指示点，注入工程专业细节 |

## 2. 四款设计方案

### 方案 A：【云端工作舱 · Bento Studio Cockpit】（首推）
- **文件**：[`app-icon-concept-a.svg`](app-icon-concept-a.svg)
- **核心意象**：微透视工作台悬浮视窗。
- **构图细节**：
  1. 窗口左侧：文件树侧边栏（抹茶绿选中项目与树形连接点）；
  2. 窗口右上：暗调黑曜石终端（`<path>` 芽绿终端提示符 `>_` 与执行日志流）；
  3. 窗口右下：API 接口药丸卡片与 Git 分支双节点流动线；
  4. 破框之芽：右上角挺立舒展的云芽，形成“严谨工程工具 + 有机生命力”的强烈视觉记忆点。
- **适用场景**：macOS 桌面客户端主图标、官方发布版本。

### 方案 B：【工台魔方 · Isometric Studio Cube】
- **文件**：[`app-icon-concept-b.svg`](app-icon-concept-b.svg)
- **核心意象**：等轴测三维积木魔方，表达模块无缝集成。
- **构图细节**：
  1. 顶面：操作台面（抹茶绿高光），中央浮雕发光的云芽图腾；
  2. 左面：代码与终端暗面；
  3. 右面：数据网格与 API 蜜桃红胶囊切面。
- **适用场景**：追求强几何感、现代科技潮流风格。

### 方案 C：【极简云芽工台 · Minimalist Studio Mark】
- **文件**：[`app-icon-concept-c.svg`](app-icon-concept-c.svg)
- **核心意象**：极简台架 + 破台而出的主干云芽。
- **构图细节**：
  1. 底部白云之上，横置一道典雅的抹茶绿工作台梁柱与双支脚；
  2. 台面中央破台拔地而起的云芽大叶，芽尖挺拔；
  3. 极微控制台与蜜桃红提示灯。
- **适用场景**：超小尺寸（16px / 32px 托盘图标）、单色丝印或高缩放兼容。

### 方案 D：【暗夜控制舱 · Studio Dark Console Edition】
- **文件**：[`app-icon-dark.svg`](app-icon-dark.svg)
- **核心意象**：完全依照 `repos/tongyun-studio/DESIGN.md` 设计令牌打造的暗色模式限定版。
- **构图细节**：
  1. 底色：黑曜石暖黑 `#26221D` $\to$ `#12100E`；
  2. 暗夜云朵：带微光的深炭灰 `#28241F`；
  3. 高对比荧光：芽绿 `#A4C48C` 与蜜桃红 `#E06D53` 发光点。
- **适用场景**：暗色主题桌面定制、开发者偏好模式。

## 3. 图标生成与尺寸适配建议

后续通过 Tauri 自动化打包生成多尺寸图标时：

```bash
# 进入 tongyun-studio 目录
cd repos/tongyun-studio

# 将选中的 SVG 渲染输出为 1024x1024 master 图标
# 使用 tauri icon 插件自动生成全平台 icns, ico, 各级 png
npm run tauri icon docs/design/app-icon-concept-a.svg
```

生成的尺寸映射：
- `icon.icns`：macOS 应用主图标（16x16 至 1024x1024 Retina）
- `icon.ico`：Windows 系统托盘与窗口图标
- `32x32.png` / `128x128.png`：Linux 与通用图标
- `tray/trayTemplate.png`：菜单栏单色微标
