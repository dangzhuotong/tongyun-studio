## 反例与修复前后

- 当前基线的 `write_project_file` 写入符号链接会改动项目外文件，新增 `file_boundaries.rs` 的拒绝断言先失败；修复后通过，外部哨兵内容不变、外部子目录不创建。
- 当前基线把 Git 状态输出整体 trim，导致首条未暂存记录被当成已暂存，`git_status.rs` 对暂存标志先失败；改用原始 NUL 记录后通过。重命名夹具曾因修改内容相似度不足被 Git 判为删除+新增，已先提交内容再测试重命名，未放宽产品断言。
- 在基线 `a27ed37` 的独立临时副本运行相同桥接/进程/Agent 用例，分别因浏览器操作返回假数据、进程读取错误无提示、暂停按钮仍启用而失败。修复工作区均通过。基线运行期间电脑休眠，不能把该轮墙钟耗时当性能指标。
- 原先 SQL/Git 提交修复已有针对性回归；本轮没有回退到更早版本重跑这两项。原始错误另有代码检查依据，不将当前通过声称为所有旧版均做过失败验证。
- 首次桌面退出测试发现 macOS 原生 Quit 直接进入 `Exit`，只处理 `ExitRequested` 会遗留子进程。补上 `Exit` 清理后，重新构建并重复同一用例，进程全部消失。首次残留的测试进程已核对身份后清理。
