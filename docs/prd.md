# 产品需求

状态：现行（首版技术底座与核心流程落地）

## 目标

以项目为中心，按需使用运行、接口、数据和版本工具的本地桌面工作台。

## 非目标

- 不连接生产数据库
- 不自动启动用户项目后台进程
- 不提交或推送代码到远程仓库
- 不伪造与独立工具间尚未确立的双向联动协议

## 用户故事与验收

| ID | 故事 | 验收 |
| --- | --- | --- |
| R-01 | 本地项目登记与持久化 | 支持选择目录或手动填入完整路径进行登记；项目登记去重持久化到本地应用配置；支持切换当前项目；支持仅移除登记而不删除磁盘文件。 |
| R-02 | 真实只读 Git 状态探测 | 自动识别当前选中项目是否为 Git 仓库；读取当前分支名、HEAD commit SHA 与未提交改动项数；探测超时安全中断，非仓库或损坏时不崩溃。 |
| R-03 | 接口请求文件统计 | 探测项目内 `.http` / `.rest` 文件数量；跳过 `node_modules`、`target` 等依赖与构建目录，有时间上限与层级保护。 |
| R-04 | 独立工具状态与拉起 | 列出 Dev、API、Database、Git 四款独立桌面工具；检测本地 `/Applications` 或用户应用目录下的安装情况；点击打开时调用系统入口启动独立应用，并明确提示在原工具中选择项目。 |
| R-05 | 本地目录快速打开 | 支持在操作系统默认文件管理器（如 macOS Finder）中打开当前选中项目的本地物理路径；若目录不存在就地提示错误。 |

需求编号稳定；改条件时同步 [testing/acceptance-tests.md](testing/acceptance-tests.md)。
